KNOWLEDGE GRAPH SCHEMA
======================

Nodes:
 Song (song_number, song_name, abode, summary, url)  
 Entity (name)  
 Theme (name)  
 MythEvent (name)  
 Philosophy (name)  
 Imagery (name)  
 Place (name)  

Relationships:
 Song -[:MENTIONS_ENTITY]-> Entity  
 Song -[:HAS_THEME]-> Theme  
 Song -[:REFERS_TO_EVENT]-> MythEvent  
 Song -[:USES_IMAGERY]-> Imagery  
 Song -[:HAS_PHILOSOPHY]-> Philosophy  
 Song -[:LOCATED_AT]-> Place  

QUICK START
===========

1. Setup Neo4j & Install Plugins
 Follow SETUP_GUIDE.md

2. Create Constraints
 Execute cypher_queries/01_constraints.cypher

3. Load Data
 Copy dataset to import directory
 Execute cypher_queries/02_data_import.cypher

4. Verify Import
 Execute cypher_queries/03_basic_queries.cypher

5. Analyze Data
 Execute cypher_queries/04_analysis_queries.cypher
 Execute cypher_queries/05_graph_algorithms.cypher

COMMAND REFERENCE
=================

Neo4j Management:
 neo4j start              Start Neo4j service  
 neo4j stop               Stop Neo4j service  
 neo4j-admin dump         Create database backup  
 neo4j-admin load         Restore database  

Database Access:
 http://localhost:7474    Neo4j Browser  
 bolt://localhost:7687    Bolt connection  

Cypher Shell:
 cypher-shell -u neo4j    Interactive Cypher shell  
 cypher-shell < file.sql  Execute query file
